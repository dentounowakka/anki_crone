GitHub Pages ready

Anki OSS を clone して改良を始める

このページは GitHub Pages でそのまま公開できる、Anki オープンソース開発ワークスペースの案内ページです。

セットアップを見る Anki 公式 GitHub

ローカルセットアップ

GitHub に接続できる環境で、以下を実行してください。

./scripts/setup_anki.sh

手動で clone する場合はこちらです。

git clone https://github.com/ankitects/anki.git anki
cd anki
git switch -c my-improvement

ミラーを使う

GitHub がブロックされる環境では、到達可能なミラーやフォークを指定できます。

ANKI_REPO_URLS="https://example.com/mirror/anki.git" ./scripts/setup_anki.sh

403 の理由

この実行環境では HTTPS プロキシが GitHub への CONNECT を拒否したため、clone が 403 Forbidden で失敗しました。通常のネットワークまたは許可済みミラーで実行してください。
